# Manuscript

Canonical prose lives here, organized by chapter and scene. Use stable scene filenames such as `01.01-opening.md`; register each scene in `planning/scene-index.yaml`.

Part cover pages use filenames such as `part-05-the-other-side-of-the-coin.md` and frontmatter declaring `document_type: "part"`, `part_number`, and `before_chapter`. They are manuscript dividers rather than scenes and are not registered in the scene index.

This file is organizational guidance, not manuscript text.
